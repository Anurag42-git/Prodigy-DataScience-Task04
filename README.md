# PRODIGY_DS_04 - Sentiment Analysis

## Objective

Analyze and visualize sentiment patterns in social media data to understand public opinion and attitudes toward various brands and topics.

## Dataset

Twitter Entity Sentiment Analysis Dataset

## Tools & Libraries Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed

- Loaded and explored Twitter sentiment dataset
- Checked dataset structure and missing values
- Cleaned the data by handling null entries
- Analyzed sentiment distribution
- Visualized sentiment percentages
- Identified top mentioned brands/topics
- Performed brand-wise sentiment analysis

## Visualizations

### 1. Sentiment Distribution
Shows the count of Positive, Negative, Neutral and Irrelevant tweets.

### 2. Sentiment Percentage Distribution
Pie chart representation of sentiment percentages.

### 3. Top Mentioned Brands/Topics
Bar chart showing the most discussed brands.

### 4. Brand-wise Sentiment Analysis
Comparison of sentiments across top brands.

## Key Findings

- Negative sentiment accounted for the largest share of discussions.
- Positive sentiment closely followed negative sentiment.
- Different brands attracted significantly different sentiment patterns.
- Social media data provides valuable insights into public opinion and brand perception.

## Project Outcome

Successfully analyzed and visualized sentiment patterns in social media data to understand public opinion and attitudes toward different brands and topics.
